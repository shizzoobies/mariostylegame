# Codex Prompt

Use this prompt in Codex:

```text
Build this into an original browser-based 2D side-scrolling platformer.

Requirements:
- Keep everything original and do not use copyrighted Nintendo names, characters, art, music, or level layouts
- Improve movement, acceleration, friction, jumping, gravity, and collisions
- Add at least 3 levels with increasing difficulty
- Add enemy patrol behavior, collectible coins, checkpoints, hazards, and a win state
- Add a title screen, pause state, game over state, and restart flow
- Add original visual polish using simple shapes or original placeholder art
- Keep the project lightweight and browser friendly
- Refactor into clean modules if helpful
- Document how to run and edit the game
```
